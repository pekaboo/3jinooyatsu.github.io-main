3時のおやつ合同公司（以下称「本公司」）就本公司提供的 iOS 应用「ポイッシュ」（以下称「本应用」）中用户信息的处理，特制定如下隐私政策（以下称「本政策」）。

1. 基本方针

本应用无需注册账户。用户登记的卡片・设置・使用记录，全部只保存在用户的设备内。本公司不会接收这些信息，也无法查看。删除本应用时，这些信息也将从设备中删除。

2. 仅保存在设备内的信息

  • 登记的卡片：名称、颜色、打开哪个应用的设置。
  • 使用记录：哪张卡片在何时出示的次数与时间。仅用于决定主页的排列顺序。
  • 各项设置：通知开关、门店类型的排列顺序、用于出示通用积分的应用选择等。

这些信息不会被发送到设备之外。

3. 位置信息的处理

本应用使用位置信息，仅出于以下目的：在主页上方显示附近的门店，以及靠近登记门店时发送通知。

  • 不保存当前位置，也不会发送给本公司。
  • 为查询周边是否有目标门店，会向 Apple 的地图（MapKit / MKLocalSearch）查询搜索范围。该通信面向 Apple Inc. 进行，并遵循该公司的隐私政策。
  • 位置信息授权可随时通过 iOS 的「设置」撤销。撤销后，仅停止显示附近门店和到达通知功能。

4. 本公司收到的唯一信息（应用追加请求）

本应用提供请求追加列表之外应用的功能。仅当用户执行该功能时，以下信息会发送给本公司。

  • 所选应用的名称、App Store ID、Bundle ID
  • 为搜索该应用而输入的关键词
  • 本应用的版本

不发送可识别设备或用户的信息，本公司也不持有此类信息。由于通信性质，IP 地址会被临时记录在分发服务商（Cloudflare, Inc.）的日志中，但本公司不会将其与请求内容关联保存。收到的内容仅用于评估是否将相关应用加入本应用的列表。

5. 第三方服务的使用

  • Apple 服务（Apple Inc.）：地图搜索、本地通知、小组件展示、通过 App Store 分发等，使用 OS 的相关功能。
  • GitHub Pages（GitHub, Inc.）：用于分发本应用显示的应用列表（目录）。仅为获取数据，不从设备发送信息。
  • Cloudflare Workers（Cloudflare, Inc.）：用于接收第 4 条所述的请求。

6. 广告・追踪

本应用不投放广告。不进行广告目的的信息收集，也不进行基于 App Tracking Transparency（ATT）的跨其他应用・网站的追踪。也未接入第三方广告 SDK 及分析 SDK。

7. 关于第三方名称与图标

本应用中显示的各公司名称与图标，基于 App Store 公开的信息展示，其商标归各公司所有。本应用与各公司相互独立，积分的累计・余额管理均在各自的官方应用中进行。

8. 儿童使用

本应用不设置询问年龄的项目，也不取得可识别个人的信息。

9. 政策的修订

本公司可能根据法律修订、服务内容变更等修订本政策。修订后的内容自在本页面公布之时起生效。
