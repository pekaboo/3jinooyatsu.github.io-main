ポイッシュ

不用翻找，一滑即出。

这是一款为了消灭收银台前「刚才用的是哪个应用来着」翻找时间的应用。
通用积分，总在同一个位置。
门店应用，靠近时自动置顶。

iOS 17.0 及以上・免费（无应用内购买・无广告）

How it works

使用方法

  1. 01选择

    开始时只需选择要用的应用。无需设置分类，也无需登记门店位置。

  2. 02靠近

    来到门店附近时，这家店的应用会出现在主页最上方。是哪家门店，会根据当时的当前位置自动判断。

  3. 03出示

    点击后直接跳转到该应用，没有中间页面。返回再打开一次，通用积分就排列在固定位置上。

  4. 04提醒

    开启通知后，到达门店时会在锁屏上提醒「在这里能积什么分」。觉得打扰，也可以直接从通知里关闭。

Features

主要功能

  • Fixed

    通用积分，总在同一个位置

    乐天积分・d 积分・Ponta・V 积分等，固定排列在主页的专属位置。顺序不会改变，店员问起时无需现场翻找。

  • Nearby

    附近的门店，自动置顶

    根据使用频率・最近使用・时段・星期，预测你现在可能要出示的卡片。范围内有门店时，最优先显示。

  • Map

    门店位置，通过地图自动获取

    无需登记门店位置。应用会通过品牌名在地图上查找周边门店，外地的同品牌门店也能同样工作。

  • Notify

    到达时锁屏提醒

    到达登记的门店时，通知你在这里能积哪些分。只显示你持有的、且实际能出示的卡片。

  • Genre

    按类型排列，顺序可调整

    便利店・咖啡店・药妆店等，日本的常见门店按类型分组显示。常去的类型可以自己移到前面。

  • Local

    无需账号。
    数据只在设备里

    没有会员注册，也不需要登录。登记的内容只保存在设备内，当前位置也不会被保存。
