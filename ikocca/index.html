How it works

使用方法

  1. 01收藏

    社交网站的帖子、地图链接，分享过来就好。AI 自动识别地点，一行添加。

  2. 02汇总

    「周末的京都」「镰仓约会候选」等，按用途自由组建合集。

  3. 03规划

    定好日期就生成旅行手册。按天分配行程，当天路线在地图上一目了然。

  4. 04留念

    去过就标记「去过啦」。附上回忆照片和一句话笔记，刻入打卡地图。

Features

主要功能

  • Collect

    社交分享，直接添加

    只需分享 Instagram・TikTok・X 的帖子。AI 从文案中识别店名・区域・类型并完成登记。

  • Map

    地图链接一键添加

    粘贴 Google 地图 / Apple 地图 / NAVER（韩国）的 URL，名称和位置自动填入。

  • Together

    两人・群组实时共享

    邀请码一邀即加入。添加和编辑实时同步，谁先提议的也一目了然。

  • Discover

    边浏览边发现的主页

    本月・心情・区域・类型・季节……横向滚动的货架让下一个目的地自然映入眼帘。今日天气也一览无余。

  • Publish

    合集以链接共享

    做好的合集可生成公开链接。没有安装应用的朋友，用浏览器就能直接查看。

  • Revisit

    打卡地图＆小组件

    去过的地方用地图图钉可视化（X / 日本 47 都道府县）。主屏小组件展示下一个「想去」和当地天气。
