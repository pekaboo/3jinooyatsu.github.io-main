# 联系表单的接收端（Google Apps Script）

适用的表单如下。

- 联系页的 3 个表单：开发・招聘・公司
- 各应用的支持页：ポイッシュ、いこっか。

提交的内容会送达以下 3 处。

- **Google 表格**：每个表单对应一个工作表，逐行记录。最左侧的「处理状态」可由团队自行更新。
  - 工作表分为「开发咨询」「招聘」「咨询公司事宜」「应用咨询」4 个。
  - 应用的表单对应工作表中有「应用」一列。
- **邮件**：发送至 info@3jino-oyatsu.com。直接回复该邮件，即可送达咨询者。
- **Slack**：向指定的频道发送通知。

此文件夹（`_contact-form/`）不会发布到网站。以下划线 `_` 开头的文件夹会被 GitHub Pages 排除在发布范围之外。

---

## 1. 创建用于记录的 Google 表格

1. 登录公司的 Google 账户。通知邮件将从该账户发出。建议使用接收 info@3jino-oyatsu.com 的账户。
2. 打开 https://sheets.new，新建一个表格。
3. 将左上角的名称改为「网站咨询」等。

工作表会在第一条咨询到达时自动创建。

## 2. 把代码粘贴到 Apps Script

1. 从表格菜单打开「扩展功能」→「Apps Script」。
2. 把左上角的「无标题项目」改名为「联系表单」。
3. 清空「Code.gs」的全部内容，把本文件夹 [Code.gs](Code.gs) 的内容完整粘贴进去。
4. 保存（⌘S）。

## 3. 发布为 Web 应用

1. 打开右上角的「部署」→「新建部署」。
2. 在「选择类型」的齿轮中选择「Web 应用」。
3. 按下表设置。

   | 项目 | 设置 |
   |---|---|
   | 说明 | 联系表单 |
   | 执行身份 | 自己 |
   | 谁可以访问 | **所有人** |

4. 点击「部署」，通过「授权访问」选择账户并点击「允许」。
   - 如出现「此应用未经 Google 验证」，由于是自己创建的，选择「高级」→「前往（项目名）」继续即可。
   - 如果「谁可以访问」中没有「所有人」选项，说明 Google Workspace 管理员限制了对外发布，需要更改管理控制台的设置。
5. 复制显示的「Web 应用」URL（`https://script.google.com/macros/s/…/exec`）。
6. 在浏览器打开该 URL，显示 `{"ok":true,…}` 即发布成功。

把 URL 配置到网站后，表单就会发送到这个接收端。配置位置是 `assets/site.js` 的 `CONTACT_ENDPOINT`。

## 4. 通知到 Slack

1. 打开 https://api.slack.com/apps，选择「Create New App」→「From scratch」。
2. App Name 填入「网站咨询」，选择通知目标的工作区。
3. 从左侧菜单打开「Incoming Webhooks」，开启「Activate Incoming Webhooks」。
4. 点击下方的「Add New Webhook」，选择通知目标频道并点击「允许」。
   - 视工作区设置，可能需要 Slack 管理员审批。
5. 复制生成的 Webhook URL（`https://hooks.slack.com/services/…`）。
   - **此 URL 等同于密钥。** 任何知道它的人都可以向该频道发消息，请勿粘贴到聊天或网站上。
6. 回到 Apps Script，点击左侧齿轮「项目设置」最下方的「添加脚本属性」。
7. 属性名填 `SLACK_WEBHOOK_URL`，值填刚才复制的 URL，保存。

脚本属性保存后立即生效，无需重新部署。

## 后续需要修改时

通过脚本属性即可修改。更改立即生效，无需重新部署。

| 属性 | 说明 |
|---|---|
| `MAIL_TO` | 通知邮件的收件地址。未设置时为 info@3jino-oyatsu.com |
| `MAIL_TO_RECRUIT` | 仅招聘使用其他收件地址时。开发为 `_DEVELOPMENT`、公司为 `_COMPANY`、应用为 `_APP` |
| `SLACK_WEBHOOK_URL_RECRUIT` | 仅招聘通知到其他频道时。开发为 `_DEVELOPMENT`、公司为 `_COMPANY`、应用为 `_APP` |

**修改代码（Code.gs）后**，需要把已发布版本替换为新版。

1. 打开「部署」→「管理部署」，点击铅笔图标。
2. 「版本」选择「新版本」，点击「部署」。

URL 不会改变，网站侧无需任何修改。

## 机制补充

- 隐藏输入框被填写的提交，视为自动提交并丢弃。
- 10 分钟内超过 30 条时，将暂停接收。
- 发送失败时，网站会显示「通过邮件应用发送」的链接。
- 即使发送到表格或 Slack 失败，只要邮件送达即视为接收成功。失败记录可在 Apps Script 的「执行次数」中查看。
